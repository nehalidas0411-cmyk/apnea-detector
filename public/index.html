The problem

Obstructive sleep apnea repeatedly interrupts breathing during sleep, yet many people are never diagnosed because overnight polysomnography is costly and needs a sleep lab. A single ECG lead is cheap and easy to record, so the question is how much apnea information it carries.

Goal

Label every minute of an overnight ECG as apnea or normal.

Key idea

Apnea produces slow, cyclic swings in heart rate and in breathing-related ECG amplitude.

Standard

Every score comes from recordings held out of training.

The data

A public PhysioNet database of overnight single-lead ECG with an expert apnea label for each minute.

Shaded amber = minutes labelled apnea by clinicians. Line = model probability (dashed = 0.5 threshold). These recordings were part of the training data, so this shows the pipeline running, not held-out accuracy.

Limitations

  • Offline analysis: neighbouring minutes, smoothing and per-recording normalisation need the whole night, so this is not real-time detection.
  • Only 35 recordings and no external validation set.
  • Not directly comparable with studies that use the fixed train and test split, which is a less strict setup.
  • Sensitivity is 70%, so about 30% of apnea minutes are missed. Screening support, not diagnosis.
Data: public PhysioNet sleep apnea ECG database. All reported scores use cross-validation grouped by recording.
